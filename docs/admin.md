# 管理后台

入口 `/admin`，简体中文，复用前台登录。仅 `admin` 角色可访问；全局路由守卫限制整个后台路径，后端每个接口再次校验角色。普通用户和版主不可进入，账号菜单仅对管理员显示入口。

后台使用独立布局，页面包含总览、用户、处罚、队列、定时任务、同步异常、错误日志、奖杯数据、攻略管理、系统设置和操作审计。表格的筛选、分页存于 URL；详情通过弹窗显示。总览、队列和调度状态每 15 秒刷新，隐藏页面停止轮询；日志手动刷新。后台页面禁用 SSR 缓存，返回 `no-store` 和 `noindex`，robots 排除 `/admin`。

API 契约见相邻后端仓库 `docs/api/admin.md`。`useAdminApi` 在现有 apiBase 下解析 `/api/admin`，兼容 apiBase 已带 `/api` 的本地配置；无需新建后台专用账号或单独的 API 地址。

## 验证与发布

```sh
pnpm test
pnpm exec nuxt typecheck
pnpm build
```

先完成后端后台表迁移并更新 Horizon，再发布前端构建，按现有 Nuxt 进程管理流程重启。不要直接修改用户角色来做生产测试；管理员开通继续走既有运维流程。

浏览器验收：登录后回到后台；所有列表与筛选可用；处罚先预览再确认；永久封禁的数据清理失败与处罚状态分开显示；排名处罚可撤销；失败任务能重试；设置保存有审计；日志仅显示脱敏文本；窄屏导航和表格横向滚动可用。未登录、无权限、依赖不可用及空记录均有对应展示。
